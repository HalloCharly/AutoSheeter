# Lethal Company HQ Google Sheets Tracker

A Python script that automatically fills in your Google Sheet while running HQ in Lethal Company.

**Required mod:** [LCStatsTracker](https://thunderstore.io/c/lethal-company/p/MikuOreo/LCStatsTracker/) on Thunderstore

---

## Requirements

- Python installed on your machine
- The **LCStatsTracker** mod installed via Thunderstore
- A Google Sheets API key

---

## Setup

**1. Get a Google Sheets API key**

Search YouTube for "Google Sheets API key tutorial" and follow a guide to create one. It only takes a few minutes.

**2. Configure the script**

Open `config.ini` and fill in your details:
- Your Google Sheets API key
- Your spreadsheet ID and sheet name
- Any other settings to your preference

Save the file after making any changes.

**3. Run the script**

Once the config is set up, just run the script and it will start tracking your HQ runs automatically.

---

## Notes

- You must save `config.ini` every time you make a change for it to take effect.
- The script will not work without the **LCStatsTracker** mod active in your game.
