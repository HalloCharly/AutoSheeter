# AutoSheeter
A python script that fills in your google sheet when doing HQ in Lethal Company.

How to use:
Use the config file to fill in all of the data to your preference. You will need a google sheet api key, which you have to get yourself by finding a tutorial on my youtube account (a_catless). Make sure to save the everytime you change something. After that, just run the script and it will start working.

ATTENTION! You can only use it with the mod "LCStatsTracker" found in thunderstore.
